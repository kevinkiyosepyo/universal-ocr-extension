Job application sites

iCIMS, TikTok Careers, Ashby, and Lever are verification targets. Their challenges can appear only after an application action. No live application has been submitted or retried by this build. A pending submission must be checked in the employer portal before starting another application.

YOUR CONNECTIONS

Keep it local.

Solver service

Start the companion service from your checkout with npm start. For visual recognition, run npm run vision and, once, npm run vision:pull in separate terminals. The vision model is about 3.3 GB.

The key stays in this browser's extension storage. HTTPS endpoints receive the images you explicitly analyze with them.

Optional browser proxy

Proxy settings apply to this browser profile. Localhost is bypassed so the solver remains reachable. Save your own proxy addresses, choose one, or restore your previous settings.

Embedded credentials are not supported. These controls do not provide proxies or rotate them automatically.
