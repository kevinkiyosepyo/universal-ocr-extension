Universal OCR

From pixels to text.

Read text on a webpage

  1. Open the page with the text you want to read.
  2. Click the Universal OCR toolbar icon, then Select a region. You can also right-click the page and choose Read text in a region, or press Alt / Option + Shift + O.
  3. Drag a box around the text. Press Esc to cancel. The selection uses a frozen image of the visible page.
  4. A workspace tab opens and reads the selected image automatically.

Use your own image

Choose Upload or paste an image in the popup. Drop an image, browse for a file, or paste a screenshot. PNG, JPEG, WebP, BMP, and GIF are supported. Animated images are treated as a still frame.

Read short codes

Choose Single line / code or Single word. Under Character options, limit the characters to digits or letters and digits if appropriate. Enable Remove all spaces for codes without spaces. Choose Read text after changing settings.

Put the text into a field

Review or edit the result, then select Insert into page. On the original page, click an editable text field. This replaces that field’s contents and sends input and change events. It never submits the form. Press Esc to cancel. Text fields inside embedded frames are not supported; use Copy text there.

Improve a result

Use a tight crop, select the text’s language, and choose a matching layout. Try High contrast for faint text or Keep original colors when automatic cleanup removes fine details. Rotate sideways images before recognition. Confidence is an estimate; review the output.

What is supported?

English, Spanish, French, German, Japanese, Korean, and simplified Chinese are bundled. Runs in desktop Chrome, Edge, Brave, and other Chromium browsers supporting Manifest V3 and Chrome 116 APIs. Firefox and mobile browsers are not included.

OCR works best on readable printed text. Handwriting, heavily distorted text, unusual fonts, and complex backgrounds may need manual correction. This is a general OCR companion, not a guarantee of recognizing every CAPTCHA or solving image puzzles.

Browser restrictions

Browser settings pages, extension stores, and some PDF viewers block capture tools. Paste or upload a screenshot instead. Local file pages may need Allow access to file URLs in the extension’s browser settings. Set or change the shortcut under chrome://extensions/shortcuts.

Privacy and permissions

Recognition, image cleanup, and language loading happen locally. No API key, analytics, or external network service is used. Settings are saved on this device. Image and result text stay in the workspace tab’s memory and clear when it closes. Captures waiting to open use browser session storage; they are removed when opened and are rejected after ten minutes. Expired captures are cleaned on the next capture and all session captures clear on browser exit.

The extension uses temporary access to a page after you click its toolbar action, context menu, or shortcut. It does not request permanent access to all websites.
